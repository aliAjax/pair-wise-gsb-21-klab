# hxwl-07 工卡与缺件放行台

按 ATA 章节登记维修工卡，管控机位 / 扭矩工具时段、工具校准与缺件挂签放行

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖；浏览器 localStorage 持久化）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 业务规则

- 工卡登记：机身（机号）、ATA章节、机位、作业时段、扭矩工具借用、缺件挂签
- 提交整卡校验，任一冲突即整卡拒绝并列出冲突类别、说明与原值：
  - 机位时段与其他已提交工卡重叠
  - 同一扭矩工具卡内 / 跨卡借用时段重叠
  - 借用起始时工具校准已过期
  - 归还判定异常的工具自动停用，停用工具不得借用
  - 存在未解除缺件挂签
- 签署：签署前缺件必须清零，校验通过后冻结并固化 v1 基线版本
- 签署后冻结：不得直接改卡；补录必须填写原因，重新过全部判定后另存新版本，版本链只读
- 工具归还：登记实际归还时间与校准封记状态；异常则工具停用；未归还不得结卡
- 结卡：已签署 + 缺件清零 + 工具全部归还
- 工卡、工具、缺件、版本链在同一存储键原子写入，刷新后一致

## 分层

- `src/data`：数据结构、种子数据、localStorage 持久化（数据）
- `src/domain`：重叠 / 校准 / 缺件 / 签署 / 结卡判定（规则，纯函数）
- `src/app`：组合数据与规则的操作 hook（应用）
- `src/ui`：界面组件（展示与交互）
