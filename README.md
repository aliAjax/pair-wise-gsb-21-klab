# hxwl-07 工卡与缺件放行台

航空维修工卡登记、缺件挂签控制与放行结卡台。由原"航空维修检查清单"扩展而来。

## 业务规则

- **工卡登记**：登记机身（机号）、ATA章节、机位、施工时段、扭矩工具、机械师。
- **整卡拒绝**：提交时任一规则不通过即整卡拒绝，冲突清单同时列出**录入原值**与**冲突原值**：
  - 机位时段与其他工卡重叠（同一机位同一时段只能派一张卡）；
  - 扭矩工具时段与其他工卡重叠；
  - 扭矩工具在校准有效期外（按借用起始时刻校验，有效期含当日）；
  - 存在未解除缺件挂签；
  - 必填项缺失或时段结束早于开始。
  - 拒绝不入库；同一条版本链的卡互不判重，被新版本取代的旧版本不再占用资源。
- **缺件挂签**：现场可补挂，签署前缺件必须清零（解除须填处理说明）。
- **签署 / 冻结**：缺件清零且填写签署人后方可签署；签署后冻结，不可直接修改。
- **补录版本**：冻结卡只能复制为补录草稿（草稿不占机位 / 工具资源），带补录原因重新通过四项校验后另存为同工卡号新版本，形成版本链；历史版本冻结留痕。
- **工具借还**：登记通过即生成借用记录并快照借用时校准有效期；归还时记录归还时间与归还时校准状态；**未归还不得结卡**。
- **刷新一致**：全部状态（工卡、工具、借还、挂签、版本链、计数器）以单一状态持久化到 localStorage，刷新后完全一致，可一键恢复演示数据。

## 分层（数据 / 判定 / 界面分离）

```
src/
  data/      数据层：类型、种子数据、localStorage 唯一存储入口
  domain/    判定层：rules 冲突/门禁纯函数、workshop 状态迁移纯函数、selectors 派生视图
  ui/        界面层：表单、工具台账、工卡/版本链、补录弹窗（只渲染与收集输入）
```

判定层零 DOM、零存储依赖，可脱离界面单测。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式）+ 原生 CSS，运行时无新增依赖；仅补充编译期 `@types/react` / `@types/react-dom`。

## 运行

```bash
npm install
npm run dev        # 开发端口 5107
npm run typecheck  # 类型检查
npm run test       # 判定层自检（node:test，经 esbuild 打包，无新增依赖）
npm run build
```
